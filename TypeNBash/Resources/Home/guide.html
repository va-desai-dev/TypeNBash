Getting started

Bring a folder, a script, or a CSV. TypeNBash keeps the surrounding tools within reach.

Install TypeNBash

  1. Download the disk image from GitHub Releases.
  2. Open the disk image and drag TypeNBash.app into Applications.
  3. Launch TypeNBash from Applications.

TypeNBash requires macOS 26 Tahoe or later and supports Apple silicon and Intel Macs. The project is currently distributed as a public beta.

Choose a workspace

Welcome-window action Where it takes you
Work Locally A workspace on your Mac
Connect over SSH Files and a terminal on another host
New Project A new project folder or an existing folder to initialize
Open Selected Project A saved project

An ordinary folder can be opened without adding project metadata. Managed projects keep their settings in a small file alongside the project. Read the project workspace reference for the storage format and remote-work behavior.

Run your first analysis

  1. Open a project containing a CSV file.
  2. Select the CSV to open its editable grid.
  3. Open Notebook.
  4. Add an analysis step, choose its variables and missing-value settings, and run it.
  5. Inspect the input summary, results, and notes.
  6. Export a Markdown report to keep a copy of the result.

Notebook steps are saved; results are recalculated when you run them. Export a report when you need a lasting record. The notebook reference covers the available tests, missing values, data captures, and export behavior.

Continue in R

Choose New R Notebook to create an editable .R script with # %% cell boundaries. Start R in the project console, then send a selection or the current cell from the editor.

R must be installed on the machine running that console. Its output stays in the console and is not imported back into the native notebook. Terminal commands use the runtimes and packages available on the active machine.

Work over SSH

Connect to your host from the welcome window. The file browser and terminal then work with that remote machine. You can save connection profiles and authenticate using a key, an agent, or a password.

The built-in Source Control and Changes views support local projects. Use Git in the SSH terminal for repositories on a remote machine.

Files and results

File Purpose
.typenbash.json Project name and output-directory setting
.typenbash-notebook.json Analysis steps and missing-value definitions
Exported Markdown report A saved record of results, notes, and tables

Project and notebook definitions use paths relative to the project. Keep them alongside the folder when copying or moving a project.

Get help or report a problem

Open an issue, join the discussion, or email vd@vadesai.com.

Include your TypeNBash version, macOS version, whether the workspace is local or remote, and the steps that reproduce the problem. For CSV or editor problems, a small sample helps; remove private information before sharing it.
