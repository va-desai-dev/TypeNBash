Get the source

Clone the repository with Git, or download the current source as an archive with curl.

Git

Clone the repository, including its history.

git clone https://github.com/va-desai-dev/TypeNBash.git

curl

Download the default branch as a source archive without Git history.

curl --fail --location --output TypeNBash.tar.gz https://github.com/va-desai-dev/TypeNBash/archive/HEAD.tar.gz
